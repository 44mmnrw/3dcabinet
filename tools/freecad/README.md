# FreeCAD Макросы и скрипты

В этом каталоге:
- `trim_to_length.FCMacro` — обрезает выбранный solid (например DIN-рейку) до целевой длины по самой длинной оси, сохраняя профиль.
- `find_coincident_points.FCMacro` — находит точки с одинаковыми координатами в скетче и накладывает на них ограничение наложения точек (Coincident).
- `find_coincident_points.py` — версия скрипта для использования в консоли Python FreeCAD.
- `remove_faces.py` — удаляет выделенные грани из solid объектов.

## Быстрый старт
1. Откройте исходную модель рейки (600 мм) в FreeCAD.
2. Выделите объект (он должен содержать хотя бы один solid: PartDesign Body или Part::Feature).
3. Запустите макрос: `Macro > Execute... > trim_to_length.FCMacro`.
4. Введите целевую длину (например 450) и подтвердите.
5. Получите новый объект `<OldName>_Trimmed`. Исходный будет скрыт.

## Примечания
- Макрос не "растягивает" если вводимая длина больше текущей — вернёт копию пересечения (фактически исходный размер).
- Точность обрезки определяется точностью исходной геометрии; для профилей с фасками и отверстиями они сохраняются.
- Булевая операция может быть медленной на очень детализированных solids.

## Диагностика
- Если результат — параллелепипед, значит исходная модель была уже простой Box.
- Если появляется сообщение об ошибке булевой операции — проверьте целостность модели (Part → Check geometry).

## Макрос: find_coincident_points.FCMacro

Автоматически находит точки с одинаковыми координатами в скетче и накладывает на них ограничение Coincident.

### Использование:
1. Откройте скетч в FreeCAD (или создайте новый).
2. Выделите скетч в дереве объектов (опционально — макрос найдёт его автоматически).
3. Запустите макрос: `Macro > Macros... > find_coincident_points.FCMacro > Execute`.
4. Введите допуск для совпадения точек (по умолчанию 0.01 мм) и подтвердите.
5. Макрос найдёт все совпадающие точки и добавит ограничения Coincident.

### Параметры:
- **Допуск (tolerance)**: максимальное расстояние между точками для их совпадения (по умолчанию 0.01 мм).

### Поддерживаемые типы геометрии:
- Линии (LineSegment)
- Дуги окружностей (ArcOfCircle)
- Окружности (Circle)
- Дуги эллипсов (ArcOfEllipse)
- Эллипсы (Ellipse)
- B-сплайны (BSplineCurve)

### Примечания:
- Макрос автоматически пропускает уже существующие ограничения Coincident.
- Результаты выводятся в консоль Python и в диалоговое окно.
- Скетч автоматически пересчитывается после добавления ограничений.

### Использование как скрипт:
Если нужно использовать в консоли Python FreeCAD:
```python
exec(open(r'C:\laragon\www\3dcabinet\tools\freecad\find_coincident_points.py', encoding='utf-8').read())
find_coincident_points()  # Для выделенного скетча
find_coincident_points('Sketch')  # Для конкретного скетча
find_coincident_points(tolerance=0.05)  # С другим допуском
```

## Скрипт: remove_faces.py

Удаляет выделенные грани из solid объектов в FreeCAD.

### Использование:

**Способ 1: Через выделение граней**
1. В FreeCAD выделите грани, которые нужно удалить (например, Face5, Face39).
2. В консоли Python FreeCAD выполните:
```python
exec(open(r'C:\laragon\www\3dcabinet\tools\freecad\remove_faces.py', encoding='utf-8').read())
remove_selected_faces()
```

**Способ 2: Прямое указание объекта и граней**
```python
exec(open(r'C:\laragon\www\3dcabinet\tools\freecad\remove_faces.py', encoding='utf-8').read())
remove_faces_by_numbers('Solid002', [5, 39])
```

### Что делает скрипт:
- Находит выделенные грани в solid объектах
- Создаёт новый объект без указанных граней
- Сохраняет placement оригинального объекта
- Скрывает оригинальный объект
- Выводит информацию о процессе в консоль

### Примечания:
- Скрипт работает только с solid объектами (Part::Feature с Solids)
- Если удаление граней нарушает целостность solid, может использоваться альтернативный метод создания оболочки
- В некоторых случаях удаление граней может быть невозможно (например, если грань критична для целостности объекта)
- Если стандартный метод не работает, попробуйте использовать встроенный инструмент FreeCAD: `Part → Defeaturing`

### Пример использования:
Если в консоли FreeCAD вы видите логи выделения:
```
# Gui.Selection.addSelection('______________________________________','Solid002','Face5',...)
# Gui.Selection.addSelection('______________________________________','Solid002','Face39',...)
```

То для удаления этих граней выполните:
```python
remove_faces_by_numbers('Solid002', [5, 39])
```

### Удаление граней встроенными инструментами FreeCAD:

**Способ 1: Part → Defeaturing (рекомендуется)**
1. Выделите грани, которые нужно удалить (Face5, Face39 и т.д.)
2. Перейдите в меню: `Part → Defeaturing`
3. В диалоге выберите грани для удаления (если не выделены заранее)
4. Нажмите `OK`
5. Создастся новый объект без указанных граней

**Способ 2: Part → Refine Shape**
- Удаляет лишние рёбра и грани, но работает автоматически (не выбираете конкретные грани)
- Меню: `Part → Refine Shape`
- Полезно для очистки модели после булевых операций

**Способ 3: Ручное редактирование через булевы операции**
1. Создайте временный объект (например, Box), который перекрывает ненужные грани
2. Используйте `Part → Cut` для вырезания
3. Или используйте `Part → Common` для пересечения
4. Удалите временный объект

**Способ 4: Part → Remove Splitter**
- Удаляет разделители (splitter edges), но не конкретные грани
- Меню: `Part → Remove Splitter`

**Когда использовать скрипт vs встроенные инструменты:**
- **Встроенные инструменты** — проще для разовых операций, есть GUI
- **Скрипт** — удобнее для пакетной обработки, автоматизации, точного контроля
