# 📐 Пример структурирования модели шкафа в FreeCAD

## 🎯 Быстрый старт

### Шаг 1: Создайте Assembly

```
1. FreeCAD → Part → Create Part
2. Назовите: "Cabinet_Assembly"
```

### Шаг 2: Создайте группы

Внутри `Cabinet_Assembly` создайте группы:

```
Cabinet_Assembly (App::Part)
├── Vertical (Group)      ← для стоек, реек
├── Horizontal (Group)   ← для цоколя, крыши, верха, низа
├── Doors (Group)        ← для дверей
├── Panels (Group)       ← для боковых панелей
├── Fixed (Group)        ← для петель, замков, ручек
└── Anchors (Group)      ← для якорных точек (опционально)
```

### Шаг 3: Добавьте теги в имена

**Правило:** Добавьте тег в конец имени объекта.

| Что масштабировать | Тег | Пример | Группа |
|-------------------|-----|--------|--------|
| Вертикальные элементы (стойки, рейки) | `[SCALE]` | `Rail_Left [SCALE]` | Vertical |
| Цоколь, крыша (верх, низ) | `[FIXED]` | `Bottom_Plate [FIXED]`, `Top_Plate [FIXED]` | Horizontal |
| Двери | `[DOOR]` | `Door_Front [DOOR]` | Doors |
| Боковые панели | `[PANEL]` | `Panel_Left [PANEL]` | Panels |
| Петли, ручки (позиция не меняется) | `[FIXED]` | `Hinge_01 [FIXED]` | Fixed |
| Замки, ригели (позиция меняется!) | `[FIXED_POS]` | `Lock_41144 [FIXED_POS]`, `Riegel_SS34 [FIXED_POS]` | Fixed |
| Якорные точки | `[ANCHOR]` | `Anchor_Bottom [ANCHOR]` | Anchors |

**Важно:**
- **Цоколь (bottom/base)** → группа **Horizontal** + тег `[FIXED]`
- **Крыша (top/roof)** → группа **Horizontal** + тег `[FIXED]`
- **Замки, ригели, направляющие** → группа **Fixed** + тег `[FIXED_POS]` (позиция меняется по высоте!)

## 📋 Полный пример структуры

```
Cabinet_Assembly (App::Part)
│
├── Vertical (Group)
│   ├── Rail_Left [SCALE]
│   ├── Rail_Right [SCALE]
│   └── Profile_Back [SCALE]
│
├── Horizontal (Group)
│   ├── Top_Plate [FIXED]
│   └── Bottom_Plate [FIXED]
│
├── Doors (Group)
│   ├── Door_Front [DOOR]
│   └── Door_Back [DOOR]
│
├── Panels (Group)
│   ├── Panel_Left [PANEL]
│   └── Panel_Right [PANEL]
│
├── Fixed (Group)
│   ├── Hinge_01 [FIXED]          ← петли (позиция не меняется)
│   ├── Hinge_02 [FIXED]          ← петли (позиция не меняется)
│   ├── Hinge_03 [FIXED]          ← петли (позиция не меняется)
│   ├── Hinge_04 [FIXED]          ← петли (позиция не меняется)
│   ├── Lock_41144 [FIXED_POS]    ← замок (позиция меняется по высоте!)
│   ├── Riegel_SS34 [FIXED_POS]   ← ригель (позиция меняется по высоте!)
│   └── Handle [FIXED]             ← ручка (позиция не меняется)
│
└── Anchors (Group)  ← опционально
    ├── Anchor_Bottom [ANCHOR]  ← Z = 0
    ├── Anchor_Top [ANCHOR]     ← Z = высота
    └── Anchor_Center [ANCHOR]  ← Z = высота/2
```

---

## 🔍 Как это работает

### При изменении размера шкафа:

1. **Масштабируются:**
   - ✅ `[SCALE]` — вертикальные элементы (стойки, рейки)
   - ✅ `[DOOR]` — двери (только по высоте)
   - ✅ `[PANEL]` — панели (только по высоте)

2. **НЕ масштабируются:**
   - ❌ `[FIXED]` — горизонтальные элементы, петли, замки, ручки
   - ❌ `[ANCHOR]` — якорные точки

3. **Позиции сохраняются:**
   - ✅ Фиксированные компоненты остаются на месте
   - ✅ Якорные точки помогают корректировать позиции

```
Cabinet_Assembly
```

## 🎨 Визуальная схема

```
┌─────────────────────────────────────┐
│  Cabinet_Assembly (App::Part)       │
│  ┌───────────────────────────────┐  │
│  │ Vertical (Group)               │  │
│  │ ├─ Rail_Left [SCALE]          │  │ ← масштабируется
│  │ └─ Rail_Right [SCALE]         │  │ ← масштабируется
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │ Horizontal (Group)            │  │
│  │ ├─ Top [FIXED]               │  │ ← НЕ масштабируется
│  │ └─ Bottom [FIXED]            │  │ ← НЕ масштабируется
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │ Doors (Group)                 │  │
│  │ └─ Door_Front [DOOR]         │  │ ← масштабируется (только Z)
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │ Fixed (Group)                 │  │
│  │ ├─ Hinge_01 [FIXED]          │  │ ← НЕ масштабируется
│  │ └─ Lock [FIXED]              │  │ ← НЕ масштабируется
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```
